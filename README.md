# Conceit · 漫画阅读器

一个使用 **Tauri 2 + React + TypeScript** 构建的本地漫画阅读器：书架式陈列、自由排序、竖向连续阅读，所有漫画都会复制进应用自维护的书库目录。

## 功能

- **书架主页**：漫画与文件夹以封面网格陈列；面包屑导航进入/返回文件夹
- **自由排序**：拖拽卡片调整顺序，拖到文件夹卡片即移入，拖到面包屑可移动到任意层级；排序持久化保存
- **连续阅读**：打开漫画后图片竖向拼接，滚轮 / 方向键 / 滑块上下滑动连续阅读
- **阅读浮窗**：点击画面显隐工具栏——退出阅读、页码、进度百分比、进度滑块、回到顶部
- **阅读进度**：自动记录并恢复每部漫画的阅读位置，书架卡片上显示进度条
- **本地导入**：
  - 「导入文件夹」选择一个或多个本机漫画目录（递归复制其中所有图片）
  - 「导入 zip」导入压缩包（自动解压）
  - 也可以把文件夹 / zip 直接拖到应用窗口
  - 导入即复制到应用自维护的书库，源文件之后移动或删除都不受影响
- **书库管理**：新建文件夹、重命名、删除（文件夹递归删除）、移动到根目录

## 快速开始

```bash
pnpm install
pnpm tauri dev      # 开发模式
pnpm tauri build    # 打包发布版
```

## 书库目录结构

书库位于 `<应用数据目录>/library`（Windows 下通常为
`%APPDATA%\com.conceit.mangareader\library`）：

```
library/
├── index.json          # 书架索引：条目、父子关系、每个容器内的排序、阅读进度
└── manga/
    ├── m1/             # 每部漫画一个目录（导入时复制/解压生成）
    │   ├── 001.jpg
    │   └── 002.jpg
    └── m2/
```

`index.json` 是唯一需要维护的状态文件；删掉它可以重置书架（不会删除已复制的图片文件）。

## 技术结构

```
src/                 前端（React 18 + Vite 5 + TypeScript）
├── App.tsx          应用状态：书架/阅读器切换、文件夹栈、拖拽导入、Toast
├── api.ts           对 Rust 命令的封装 + 前端侧排序/统计工具
├── types.ts         与 Rust 数据模型对应的类型
└── components/
    ├── Shelf.tsx    书架：网格、导入、右键菜单、拖拽排序
    ├── Card.tsx     漫画/文件夹卡片（封面、进度、拖放指示）
    ├── ContextMenu.tsx
    └── Reader.tsx   阅读器：竖向滚动、浮窗工具栏、进度恢复、键盘操作

src-tauri/           后端（Rust + Tauri 2）
├── src/library.rs   书库模型：索引持久化、自然排序、目录复制、zip 解压
├── src/commands.rs  Tauri 命令层（快照/增删改/排序/进度/导入）
└── tauri.conf.json  桌面配置（asset 协议加载本地图片）
```

### 实现要点

- **自维护书库**：导入时把图片复制进 `library/manga/<id>/`，书库与源目录完全独立
- **asset 协议**：前端通过 `convertFileSrc` 加载书库内的本地图片
- **自然排序**：`page2.jpg` 排在 `page10.jpg` 之前，符合漫画页码习惯
- **进度恢复**：退出或滚动时节流写入 `index.json`，重开时按比例恢复滚动位置

## 已知限制

- 拖拽排序基于 HTML5 Drag & Drop，触屏设备暂不支持
- 超大漫画（数百页）会一次性加载全部图片，内存占用较高
